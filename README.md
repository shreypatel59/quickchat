# Quick Chat

## Overview

Quick Chat is a modern chat application developed using the MERN Stack. It enables users to communicate through a responsive and user-friendly interface.

## Features

* User Authentication
* Real-Time Messaging
* Secure Login and Registration
* Responsive Design
* Modern User Interface
* Fast Communication System

## Technologies Used

* MongoDB
* Express.js
* React.js
* Node.js
* JavaScript

## Project Architecture

Frontend:

* React.js

Backend:

* Node.js
* Express.js

Database:

* MongoDB

## Installation

### Clone Repository

git clone <repository-url>

### Install Dependencies

Frontend:
npm install

Backend:
npm install

### Start Application

Frontend:
npm start

Backend:
npm run dev
